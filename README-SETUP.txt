LIAM'S PRIVATE DATING APPLICATION

Upload index.html, styles.css and script.js into the root of your GitHub repository.
Then enable GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.

EMAIL SUBMISSIONS
The form is configured to email Liam's answers to charliecampbell1108@icloud.com using FormSubmit.
After publishing, submit one test application. FormSubmit should send an activation email to that address.
Open the activation email and confirm the address. Later submissions should then be emailed to you.

Important:
- FormSubmit is a third-party email service; delivery depends on its service and your email provider.
- This has not been live-tested on your GitHub Pages site yet.
- Anyone with the website URL could technically open it, so keep the link private.
- The form sends the answers Liam enters, not photos or device information.

Photo files are in the assets folder (you.jpeg and liam.jpeg). Keep the assets folder when uploading to GitHub Pages. The original photos are used as-is.
